# Hermes代理安装工具 miu edition v1.5.4

## 主要功能

- 自动检测本机 V2rayN，并只为本程序启动的 Hermes 安装、更新和桌面端进程注入代理。
- 支持运行官方安装器、`hermes update` 和 Hermes Desktop。
- 支持按 Git 提交号、发布标签或分支安装指定版本。
- 可获取官网最新稳定版或检测本机版本，并将选择保存到随附 INI 文件。
- 图形化显示安装阶段、进度和完整日志；网络故障自动重试，长时间无输出会停止并报告错误。
- 支持高 DPI，页签切换采用单帧重绘，减少界面闪烁。

## 使用方法

解压 Windows 压缩包，运行 `HermesProxyBridge.exe`。
