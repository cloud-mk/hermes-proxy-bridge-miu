# Hermes代理安装工具 miu edition v1.5.3

## 本版变化

- 选中标签与当前页面统一使用清晰的浅蓝色，未选标签使用更深的灰蓝色，白色功能框保持独立层级。
- 官网最新稳定版本号与本机当前版本号改为并列显示和并列获取按钮。
- 点击任一获取按钮后自动填入指定安装版本，并保存到随附 INI。
- 增加本机版本跨电脑携带用途的完整说明。
- 删除“填入稳定版”和“复制版本”按钮及功能。
- 本机版本检测不再写入剪贴板。
- 修复高 DPI 缩放时“安装上述指定版本”按钮被上方固定内容挤出功能框的问题。
- 已在真实 Windows 窗口的普通、最大化和页签切换状态下完成界面检查。

## 安装

解压 `HermesProxyBridge-v1.5.3-windows.zip`，运行 `HermesProxyBridge.exe`。

程序未签名，Windows SmartScreen 可能显示“未知发布者”。
