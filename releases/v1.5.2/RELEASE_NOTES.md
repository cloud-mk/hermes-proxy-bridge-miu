# Hermes代理安装工具 miu edition v1.5.2

## 本版变化

- 明确区分“已找到 V2rayN”和“已启动 Hermes 专用代理”。
- 未启用时显示黄色状态条；启用后才显示绿色状态条。
- 按钮会切换“启动 Hermes 专用代理 / 关闭 Hermes 专用代理”。
- 未启动专用代理时，安装、更新、桌面端和指定版本安装按钮保持禁用。
- 按要求统一标题、副标题、代理操作、日志和指定版本页文字。
- 删除桌面快捷方式功能。
- 删除命令预览功能。

## 安装

解压 `HermesProxyBridge-v1.5.2-windows.zip`，运行 `HermesProxyBridge.exe`。

程序未签名，Windows SmartScreen 可能显示“未知发布者”。
