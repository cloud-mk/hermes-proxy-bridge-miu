# Hermes代理安装工具 miu edition v1.5.2 界面审计

日期：2026-10-01（Asia/Shanghai）

## 状态语义

- 红色：没有找到可用的 V2rayN，提示先启动 V2rayN。
- 黄色：已找到本机 V2rayN，但尚未启动给 Hermes 安装/更新使用。
- 绿色：Hermes 专用代理已经启动，后续由本工具启动的进程树会继承代理。

开关按钮会在“启动 Hermes 专用代理”和“关闭 Hermes 专用代理”之间切换。专用代理未启动时，代理操作和指定版本安装按钮均保持禁用。
