# Hermes代理安装工具 miu edition v1.5.4 审计

日期：2026-10-02（Asia/Shanghai）

## 功能变化

- 代理地址只来自 V2rayN 自动检测；旧 INI 中可能存在的 `ManualProxy` 不再读取或写入。
- 代理状态区域扩大，按钮靠右排列并以蓝色/绿色突出当前开关动作。
- 首个官方安装脚本下载最多尝试 3 次。
- 支持阶段协议的指定版本安装只对当前失败阶段执行最多 3 次网络故障重试。
- 非网络错误立即停止，不会用重试掩盖脚本、权限、磁盘或版本兼容问题。

## UI 与 DPI

- EXE 内嵌淡色猫咪透明水印，不依赖临时文件或绝对路径。
- 水印没有文字、用户名、目录或其他个人信息；画布空白区使用真实 Alpha 透明，不再携带整张白色底图。
- 水印由独立的逐像素 Alpha 拥有窗口覆盖在日志框、按钮、文本框和面板之上；扩展窗口样式与命中测试均设置为鼠标穿透和不激活。
- 页签不再分别重绘大幅背景；主窗体和主要布局容器使用双缓冲，切页期间合并布局，并先显示目标页再隐藏旧页，避免中间空白帧。
- 切页时递归冻结页面容器和所有已创建句柄的子控件，完成一次布局后以一次 `RedrawWindow` 递归提交；当前页签重复点击不执行操作。
- 切页期间代理检测计时器与水印暂时停止显示更新，页面提交后恢复；代理检测值不变时不再重复改写界面属性。
- 状态字体使用缓存实例，功能框使用不透明白色背景，避免周期性字体分配和半透明擦除。
- 主窗口首次显示并确定 DPI 后，递归创建两个页面的原生控件句柄并完成隐藏页布局，消除首切页的惰性创建成本。
- Windows 清单声明 `PerMonitorV2,PerMonitor`；固定布局值按当前系统 DPI 换算。
- 200% DPI 渲染检查未发现标题、页签、按钮和日志栏文字截断。
- 代理页与指定版本页的离屏合成截图均确认水印跨越日志框和日志按钮显示，文字仍可读。
- 真实 Windows 窗口完成代理页、指定版本页、重复当前页和返回代理页的动态切换检查；用户确认闪烁已经消失。
